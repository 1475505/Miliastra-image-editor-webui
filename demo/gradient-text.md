# 双色渐变字 Lua 示例

- [gradient-text.lua](gradient-text.lua)：用当前拼图工具的 Lua 导出链路生成，运行时动态创建 3 个控件。
- [gradient-text.json](gradient-text.json)：同一作品，可导入本工具继续编辑。
- [gradient-text-preview.png](gradient-text-preview.png)：模拟器预览，透明背景，不是真机验收截图。

## 使用

1. 在千星沙箱准备两个“仅存为模板”的干净客户端模板：图片、文本框。
2. 把它们的实际模板索引填写到 Lua 顶部 `IMAGE_PREFAB_ID` 和 `TEXTBOX_PREFAB_ID`。默认 0 表示未配置，脚本会提示而不是猜索引。
3. 建立该 Lua 的脚本映射，挂到客户端控件容器中的**专用空容器节点**，保存并试玩。这个脚本会设置宿主尺寸，不要挂在已有作品的根节点或被实例化的模板上。

无需手动创建文字层或分别挂脚本。OnStart 自动创建：

```text
脚本宿主（800×360）
├─ 蓝色文字“星间来信”
└─ 透明矩形图片蒙版（920×220，相对文字中心 X=310）
   └─ 金色文字“星间来信”（相对蒙版 X=-310，与蓝字重合）
```

两份文字均固定字号 72、居中、无描边、透明背景。蒙版采用图片 `StaticReference / 100001`，自身颜色 alpha=0，启用遮罩与 Pixel 羽化：X=300、Y=0。左边界为相对文字中心 -150，右边界为 770，因此只有左侧渐入穿过字面，右侧渐出远离字面。精确原生羽化曲线没有在本示例中测量。

## 编辑

将 JSON 或 Lua 导入拼图工具；两层文案、字号、尺寸、对齐应保持一致。颜色分别在各层的基本属性中修改；顶层的蒙版参数位于“图元 → 高级”。改变渐变跨度时同时考虑蒙版偏移、宽度和羽化宽度，避免另一侧羽化进入字面。

这是静态渐变，不带 Tween。当前百分比预览有近似策略，因此本例选用已有基础真机观察的 Pixel 模式。普通图元只启用羽化会渐隐，不会自动变成双色；双色来自底层完整文字和另一颜色副本的叠加。

## 验证

同一 Lua 已通过编辑器回导、已有 Fengari 控件契约检查，以及模拟器实际执行：3 个运行控件、资源 100001、透明蒙版、父子关系和两份文字最终位置一致、无运行错误。PNG 像素检查存在左侧蓝色、右侧金色及中间混合色。运行端为 `simulator`，该示例的 `device_status=pending`；测试使用的 1234/5678 仅为合成模板，未写入交付脚本。一次性生成/验证脚本已清理。
