# 蓝金渐变字示例

![渐变字预览](gradient-text-preview.png)

- [JSON](gradient-text.json)：导入编辑器继续调整。
- [Lua](gradient-text.lua)：填写图片和文本框模板索引后，映射并挂到专用空客户端容器节点。

示例由两份重合的“星间来信”和一个透明图片蒙版构成：蓝字完整显示，金字由蒙版左侧羽化逐渐显现。

两份文字的内容、字号、尺寸、对齐与位置需要保持一致。颜色在基本属性里修改；顶层金字的蒙版在高级属性里调整。默认是 Pixel 羽化，X=300、Y=0；窗口较宽并向右偏移，避免右侧羽化进入字面。

这是静态示例。图片来自模拟器预览，不是真机验收图。配置步骤与功能范围见 [Lua 导出与蒙版](../docs/lua-mask.md)。
