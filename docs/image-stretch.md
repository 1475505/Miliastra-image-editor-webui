# 图片类型：基础／拉伸

[返回使用指南](README.md)

选中图片，在「图元 → 基本 → 图片类型」切换。蒙版也有独立的图片类型设置。

| 类型 | 适合什么 | 缩放方式 |
|---|---|---|
| 基础 | 图标、插画、需要整体缩放的图片 | 整张图片随宽高缩放 |
| 拉伸 | 圆角底板、边框、分隔线 | 按图片的三／九切片边框拉伸，尽量保留角部形状 |

只有素材边框中至少一项大于零时提供拉伸；普通图片默认使用其可用类型。无边框或边框文件缺失时只有基础。原始尺寸下两种模式可能相同，改变宽高更容易看出差别。

## 添加和替换

- 图形库中的拉伸编号以主题色提示，缩略图显示登记的拉伸示意；未登记或加载失败则显示原图。
- 新增图片的可拉伸方向默认宽 136／高 96，未切片方向保留原始厚度；可在属性里自行修改。
- 切换类型保留当前宽高。收藏图元保留其保存的尺寸与类型。
- 普通图片替换 ID 后按新素材判断能力；显式基础选择保留，无法使用的拉伸会调整为基础。
- 蒙版的“保持默认”不强制写原生类型；网页仅根据素材边框推定预览。

## 导出时的区别

- **JSON** 保存 ID、类型与尺寸，适合继续编辑。
- **Lua** 设置对应图片类型；原生图片不支持切换时按脚本的兼容策略处理。
- **CSS/SVG** 将当前尺寸的拉伸效果内嵌成 PNG，同时保留可回导的素材信息。直接修改导出图片的宽高只会缩放位图；要重新切片，请回导后调整再导出。
- **PNG** 按当前尺寸渲染。
- **GIA** 的拉伸字段采用兼容映射，尚未获得该素材组格式的完整真机确认，请在导入后检查。

画布和导出都使用原图与边框，不会把固定尺寸的缩略图当作作品贴图。AI 可用 `get_asset_info` 查看可用类型和尺寸，详见 [WebMCP](webmcp.md)。
