# 三轴旋转与翻面

[返回使用指南](README.md)

选中图元，在「图元 → 基本 → 变换」输入 X/Y/Z 角度。单位为度，支持小数；复位按钮同时归零三轴。

- **X**：上下倾转，180° 上下翻面。
- **Y**：左右倾转，180° 左右翻面。
- **Z**：画面内旋转，逆时针为正；画布旋转手柄修改这一项。

X/Y 为 90° 时图元侧立，画面可能不可见。请从图层列表选中后修改角度。宽高仍是原平面尺寸，不要为补偿倾转而先缩小尺寸。

JSON、收藏与 Lua 保留三轴；GIA 写入旋转参数；CSS/SVG 使用二维投影及回导信息。PNG 与网页显示投影后的效果。复杂外部 CSS/SVG 变换不保证能还原为相同角度，完整作品优先保存 JSON。

网页采用正交投影。单轴图片倾转有真机观察依据，混合轴、不同设备及导出格式仍需检查最终效果；不提供任意透视或三维场景编辑。

通过 JSON 或 WebMCP 设置时，`rotation` 表示 Z，`rotationX` 和 `rotationY` 缺省为 0：

```json
{"id":"flip","type":"triangle","x":150,"y":150,"width":100,"height":60,"rotation":0,"rotationX":60,"rotationY":180,"color":"#87cafa","opacity":1}
```
