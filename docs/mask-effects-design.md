# 遮罩与渐变效果 · 技术方案 / UI 提案

状态：**待评审提案，尚未接入产品**。日期：2026-10-12。适用项目：Miliastra Image Editor WebUI。

配套稿：[交互式 UI 稿](ui/mask-effects.html)，无需服务、依赖或联网，双击打开。可切换三种示例、修改文字/配色/羽化、拖动手柄、查看原始内容、撤销和查看导出计划。它是交互示意，不代表 GIA/Lua 导出已经实现，也不是新的真机验证。

API 复核补充：[完整相关属性清单](mask-effects-api.md)。原生能力包含 **Pixel / Percentage 两种羽化模式、X/Y 宽度、水平/垂直范围、反转和五种填充**。下文 Pixel-first 仅表示首发预览与配方实现范围，不能当作原生能力上限；现有 HTML 稿仍只演示三个 Pixel/硬边配方，完整属性页签按该清单修订。

Lua 必要性更正：**静态蒙版、羽化和静态渐变不以 Lua 为必要条件。** 控件树和参数能完整写入目标客户端 GIA 时可直接配置；Lua 用于运行时生成/设置、联动和动画，也可暂时补足导出器未覆盖的字段。此前 A–G 是脚本切换实验，不是“无 Lua 静态 GIA”专项验收，不能把两者混为一项证据。详见 [资料与 Lua 依赖](mask-effects-api.md#9-现有资料与-lua-依赖结论)。

## 1. 产品目标与第一版决策

让用户用少量可编辑参数，为原生文字、基础图形及可着色素材添加局部视觉效果。

**第一版三个入口：创建裁切组、双色渐变、软边高光带。**

- 编辑模型保存一份源内容，效果副本只在编译后产生；改字、字号、形状后所有副本同步。
- 保留现有浅绿三栏布局。左侧展示源图层树，中间编辑效果手柄，右侧展示参数和成本。
- 原生属性模型包含像素/比例羽化及四个羽化数值、反转、填充。首发精确性核验聚焦矩形硬裁切和横/纵像素羽化；比例参数的字段关系和单位尚未确认，不做自动换算。动画、任意角度渐变、圆形软遮罩、多色渐变配方后续扩展。
- V1 每个节点最多一个着色效果，可与一个裁切组组合；不引入任意效果栈及递归着色副本。
- 静态效果优先完整保存控件树与原生参数；Lua 是可选输出，不以增加“效果”页签就强制生成脚本。客户端 GIA 需要独立出口并验证：静态包可以不含脚本，动态/初始化包按需携带。**现有素材组 GIA 的画布遮罩不能充当客户端图片羽化遮罩。**
- 控件数量是编译计划的精确计数；不要写死“3 控件”适用于所有组合。

## 3. 能力与证据边界

来自既有 MASK v1 真机回传：PC 键鼠、约 1600×900 UI 画布、静态矩形图片 100001、宿主 scale=1。

- 图片遮罩影响直接子图片、隔层子图片及文字；不影响兄弟控件。
- `imageColor` alpha=0 不取消矩形遮罩，区域内子内容仍可见。
- Pixel X/Y 分别柔化左右/上下，宽度 0 是硬边，40 比 20 更宽。
- 不透明遮罩组在 E/F/G 图中有更亮的软边，不能声称软边颜色与透明组逐像素一致。

**设计中的线性覆盖率、组级合成、非 1 缩放后的宽度换算是预览策略，不是完整真机公式。** 首发生成的遮罩统一透明，避开不透明遮罩底色参与混色的歧义。

未测：百分比模式、range 字段的独立作用、反转、非矩形轮廓、嵌套遮罩、精确衰减曲线、点击命中。API 已明确声明的选项保留在能力清单与数据模型中，UI 区分“原生已声明”和“本工具视觉已核验”。不能把尚未核验的视觉语义写成 API 不支持。

证据位置（完整知识工作区）：`E:/qxqy-lua/knowledge/fact.md` 的 MASK v1、`probes/mask-softedge-20261011/`。模拟器实现参考：`studio/play/image-mask.js`、`studio/host-png.js`、`studio/play/pixi-renderer.js`。本工具部署及单元测试不得依赖该外部目录。

## 4. UI 与操作流程

### 4.1 主界面

```text
千星图片编辑器   撤销/重做   文档名称                 原始/效果   导出
┌────────────────┬─────────────────────────────┬───────────────────┐
│ 图层 | 图形库  │ 缩放 · 手柄 · 画布尺寸       │ 属性 | 效果       │
│                │                             │                   │
│ ▼ 裁切组       │         选中的作品          │ 效果类型          │
│   ▼ 徽章       │       ───●────●───          │ 颜色 / 方向       │
│     标题 · fx  │       拖动起点/终点         │ 起止 / 羽化       │
│     图形       │                             │                   │
│ 原始内容 1 份  │                             │ 源图元 1 → 控件 3 │
│ 自动副本折叠   │                             │ 原生结构 [查看]   │
└────────────────┴─────────────────────────────┴───────────────────┘
当前选择 · 编辑反馈                                  控件计数与导出模式
```

主入口是选中后的“添加效果”菜单与右键菜单。UI 稿左侧的三张配方卡是快速体验入口，正式产品复用同一命令。左侧图层树默认只显示源图元和用户组；“查看原生结构”是只读说明，避免把编译副本暴露成可独立编辑图层。

原生配置页签应按“遮罩 → 边缘羽化 → 按进度填充”组织：羽化模式提供像素/百分比，并保留宽度 X/Y 和范围 H/V 四值；填充按形状显示方向/起点及进度。它与双色/高光预设是不同层级，原生字段清单见 [API 核对 §8](mask-effects-api.md#8-对效果页签的修订建议)。

### 4.2 双色渐变

1. 选中文字或可着色图元/同色目标组 → 添加效果 → 双色渐变。
2. 设置底色/顶色、横/纵方向；在画布拖动两个手柄定义过渡起止位置。
3. 改文字只改源文本，所有效果副本共用同一排版。预设为固定字号、透明背景、统一描边。
4. 单独切换“原始内容”临时旁路效果，只用于比较，不改保存值。

V1 默认允许纯文本、六类基础图元、已知可染色素材。富文本中的内联颜色、半透明文本背景、复杂不同色组会改变叠加结果，必须给出具体不支持原因，不能悄悄删标签或颜色。任意彩色贴图的“绝对换色”不是通用能力。

首发渐变的目标填充默认完全不透明（字形/贴图边缘抗锯齿仍可透明）；原内容本身半透明时，重合副本会改变合成 alpha，不能直接承诺等价换色。需要支持该类内容时，应定义额外的组透明度策略并独立验收，V1 明确提示限制。

### 4.3 软边高光带

选中目标 → 添加高光带 → 设置颜色、强度、宽度、羽化 → 拖动中心手柄。静态预览；“扫光动画”只在后续阶段开放。高光副本通过内容颜色 alpha 调强度，遮罩图片自身 alpha 始终为 0。

### 4.4 裁切组

选择同父、层序连续的多个图层 → 创建裁切组。以外接框初始化矩形，保留原来的视觉位置和层序；用户移动裁切框时内容固定，移动组时内容与裁切框一起移动。

不连续层序的选择不能直接打包后跨越其它图层：提示“请先把目标图层排成连续区间”。V1 裁切为硬边，已有渐变可作为它的子内容；软裁切整组需沿用统一组级合成。

### 4.5 交互细节

- 手柄拖动以组局部坐标保存；滚轮缩放只改变查看倍率。方向切换保留范围比例并重新映射轴。
- 拖动开始保存快照，移动只更新 preview，松开提交一次撤销记录；Escape 取消，箭头键微调 1，Shift+箭头微调 10。
- 隐藏/锁定针对整组；点击效果副本映射回源节点，禁止选到内部重复文字。
- 删除效果恢复源内容；解组保留世界变换与层序，存在无法表达的 shear 时拒绝无损解组并说明。
- 1280px 宽桌面保留三栏；更窄时左侧可收起、属性面板切抽屉。手机作为查看/参数调整，精确拖拽为桌面优先。

## 5. 场景数据 V2

保留 `elements[]`（兼容现有导入入口），引入 `schemaVersion: 2`、可选 `parentId` 和 `type: 'group'`。只增补明确字段，组层序中的 zIndex 仅对同父节点比较。缺版本旧场景按 V1 迁移，所有 parentId=null，稳定保留原来的全局排序。

```ts
type SceneDocumentV2 = {
  schemaVersion: 2;
  canvas: CanvasModel;       // canvas.mask 仍是旧素材组全局遮罩
  elements: SceneNode[];
  meta: MetaModel;
  library: SceneLibraryV2;
};

type SceneNode = (SceneElement | GroupElement) & {
  parentId: string | null;
  effect?: Gradient2Effect | HighlightEffect;
};

type GroupElement = {
  id: string; name: string; type: 'group'; parentId: string | null;
  x: number; y: number; width: number; height: number;
  rotation: number; scaleX: number; scaleY: number; zIndex: number;
  visible: boolean; locked: boolean;
  clip?: { type: 'rectangle'; x: number; y: number; width: number; height: number };
};

type Gradient2Effect = {
  id: string; kind: 'gradient2'; enabled: boolean;
  direction: 'horizontal' | 'vertical';
  from: string; to: string;   // #RRGGBB；V1 色标不设独立透明度
  start: number; end: number; // 目标局部坐标，两端可超出内容框
};

type HighlightEffect = {
  id: string; kind: 'highlight'; enabled: boolean;
  direction: 'horizontal' | 'vertical';
  color: string; opacity: number; // 0..1，作用于覆盖内容
  center: number; width: number; feather: number;
};
```

叶子扩展使用 discriminated union，不能让 group 默认为“矩形图片”。group.clip 与 canvas.mask 的名称和数据生命周期完全分开。上方类型是提议结构，实施时抽出公共 base 类型避免交叉属性冲突。

上面的 `effect` 为工具配方，不是原生字段全集。图片/蒙版节点另保存 [NativeImageEffects](mask-effects-api.md#8-对效果页签的修订建议)，包含两种羽化模式和全部四个数值字段；不能只有 `feather: number`。配方和原生编辑应设明确的所有权：默认配方生成内部字段；用户选择“转为原生蒙版”时展开并解除配方管理，避免两套配置互相覆盖。

### 必须固定的语义

- 叶子仍使用中心坐标。加入组后位置转为父组局部中心坐标（编辑器 y 向下）；重挂父级先计算 `newLocal = inverse(newParentWorld) × oldWorld`。
- V1 用户组只提供平移、Z 旋转、等比缩放；resize 组框不默认缩放内容。新组框中心固定锚点及轴心，兼容层级导出。
- 旧场景 X/Y 旋转保留；被效果作用的分支若带非零 X/Y，V1 显式提示暂不支持，不能默默烘焙为另一种形状。
- 叶子已有锚点、轴心等参数保留在源内容；效果编译时先解析最终局部几何，不允许两份文字使用不同锚点适配。
- 拒绝循环 parent、悬空 parent、重复 id、非有限数和负尺寸；显式未来版本拒绝导入。0 尺寸裁切可在运行时动画出现，含义为空覆盖，不是关闭效果。
- 旧收藏迁移为单节点；组收藏保存以根为入口的子树，粘贴时统一重分配 id/effect id，不携带外部引用。

## 6. 效果编译：源内容 → 原生控件树

新增受限的效果编译层，所有导出使用同一语义计划 `RenderPlan`。它不执行 Lua，只生成确定的控制树、资源引用、绘制顺序、统计与诊断。

```text
Scene V2
  → validate / migration
  → resolve group transforms & text layout
  → lower effects (source copies + transparent image masks)
  → RenderPlan { roots, controls, resources, diagnostics, cost }
  → Web preview / PNG / SVG-CSS / Lua / client-GIA adapter
```

前端需要同步交互，用 TS 编译器；后端导出用 Python 对等编译器。两端共享版本化 IR/schema 和小型合成 golden fixtures（预期来自手算几何），不共享运行时外部源码目录。编译器不得把图元先栅格化成图片再导出为虚假的“原生控件”。

### 6.1 双色渐变的几何

设目标局部内容边界为 `[xmin, xmax]`，横向过渡 `[a,b]` 且 `b>a`，`f=b-a`。

- 完整底色副本始终存在。
- 顶色副本置于透明矩形遮罩下。
- 左边界 `L=a`；右边界 `R≥max(xmax,b)+f+margin`，将不需要的右羽化边移出内容。
- `softEdgeMode=Pixel`，`softEdgeWidthX=f`，Y=0，反转关闭、填充关闭。
- 遮罩中心 `m=(L+R)/2`，子内容从公共父坐标转到遮罩局部坐标；纯平移时 `child.x=source.x-m`。一般变换必须用矩阵逆变换，不能只减位置。
- `a=b` 用硬边阶跃，不除以零；反向渐变通过交换颜色及坐标解释处理，不依赖未验证的 reverseMaskArea。
- 垂直方向同理，在编辑器 y-down 与客户端 y-up 的统一边界换算一次。必须明确“起色在上/终色在下”的视觉含义。

字体变化后按源内容布局重新计算边界；文本框宽度不能冒充真实字面。前端使用实际字体/Canvas 测量用于交互；导出保持原生排版参数，真机字体度量差异保持边界说明。V1 禁止固定字号副本与自适应副本混合。

### 6.2 高光带

完整底色 + 透明窄矩形遮罩 + 浅色副本。中心、带宽、羽化决定局部权重，高光 opacity 写到副本颜色 alpha。V1 将 `feather≤width/2`，避免相对软边交叠后形状含义不明确。

### 6.3 成本

对 K 个可染色叶子：双色/高光为 `2K+1` 个绘制相关控件，加上必需的逻辑组；单字例 K=1 为 3。裁切组 K 个叶子加一个透明图片遮罩为 K+1。叠加效果按实际 IR 计数；裁切组外套双色文字为 4 个效果相关控件，不宣称永远 3。

UI 分别显示源叶子、颜色副本、遮罩和公共宿主，不把逻辑组隐藏在估算里。控件预算为项目可配置的提示，不虚构官方硬上限。

## 7. 渲染一致性与性能

关键顺序：**先合成一个遮罩组的内容，再应用一次覆盖率**。不是每个重叠图元先变透明再相叠。独立兄弟遮罩按身份分别合成；嵌套逐层处理。此为 Web/PNG 一致性的明确策略，尚不是所有真机合成细节的证明。

- 浏览器预览：SVG/Canvas 实现统一组结构；SVG alpha mask 用透明度而非素材亮度；maskUnits、maskContentUnits、有限 mask region 均显式写出。不只用 `background-clip:text` 伪造与原生复制树不同的预览。
- 裁切与颜色遮罩使用两个逻辑容器层，避免共用一个 mask 引用导致覆盖。选择框和辅助线处在效果外层，不受裁切影响。
- PNG（Pillow）：只为遮罩包围盒与画布交集分配离屏层，缓存逆矩阵，每组合成一次；不为每个 10×10 图元扫描 2048×2048。
- 字号、文案、变换改变使布局及蒙版缓存失效；纯颜色变化复用几何；高光位置只移动遮罩及补偿内容。
- 不使用 CSS mix-blend-mode、blur 或发光滤镜暗示客户端具有这些能力。
- UI 命中采用源节点映射；被裁切掉的内容允许从图层树选择，“显示原始内容”帮助编辑。游戏内事件命中不由视觉效果推导。

## 8. 导出矩阵和回导

| 格式 | V1 目标 | 不可丢失的内容 |
|---|---|---|
| JSON V2 | 完整源数据，无副本膨胀 | 层级、效果、收藏、版本 |
| PNG | 静态效果合成结果 | 透明背景、有限裁切、组级 alpha |
| SVG / CSS | 等效分组展示 + 编辑元数据 | 保留效果参数用于本工具回导；外部任意 mask 不保证可编辑还原 |
| Lua | 原生客户端树生成；明确所需模板 | 父级、图片资源、遮罩、羽化模式和四值、填充/反转、层序、正确对齐、清理；仅输出已核对接口与原始参数 |
| 旧素材组 GIA | 继续服务无效果旧场景 | 有客户端效果时禁用该选项并解释；不得静默丢效果 |
| 客户端静态效果 GIA | 新出口，层级/属性写入通过验收后开放 | 服务端客户端控件容器、客户端子树和原生参数；不强制带 Lua |
| 客户端效果 GIA + Lua | 需要初始化补偿、运行时联动或动画时使用 | 静态资产 + 所需脚本源码与挂载，标明脚本用途 |

### Lua

效果场景直接把 RenderPlan 转成 `CONTROLS_V2` 字面量及小型客户端构建运行时，不再经过扁平旧 GIA parser。复用 vendored 代码时保持原文件不变，新增应用层适配。

单独脚本要求按计划提供 IMAGE_PREFAB_ID / TEXTBOX_PREFAB_ID，只有确需普通组控件才增加 CONTAINER_PREFAB_ID。由用户真实模板身份配置，不填造假的可运行索引。整合 GIA 路径可把静态树和挂载一并打包。

父先子后构建，先隐藏并设置资源/状态，再显示；图片 `SetImage(StaticReference,100001)` 独立于模板索引。不能无条件写 `imageType`。失败时一次聚合报告并释放本轮创建资源；OnDestroy 不重复销毁宿主正在回收的子树。

回导只读取受限字面量与 V2 元数据，不执行上传代码。绘图摘要应包含 parent/effect/资源/文字参数；仅修改模板索引不影响元数据恢复，修改绘制树后重读数据并标记“已转为展开控件”，不能返回陈旧源效果。

### 客户端整合 GIA

新增 `giaTarget: 'material' | 'client-effects'`，明确格式差异。通过新的可维护 codec 模块构建客户端树，核对 GUID、资产编号、四平台变换、图片/文本字段、脚本映射与挂载。不要把 `backend/vendor/gia` 的素材组模板字段复制为客户端结构。

`client-effects` 按编译计划决定是否带脚本：静态节点及字段全部可编码时不带；需要启动赋值补齐字段时带最小初始化脚本并标明；存在时间变化/运行时交互时再带对应逻辑。不能因为某字段未接入本工具编码器，就声称官方效果必须由 Lua 实现。

项目运行时不能 import `E:/qxqy-lua/simulator`。若要复用 codec，选择固定版本的可发布包/隔离适配或将必要代码按许可与 provenance 纳入项目。**具体选型前核对许可证；不直接混入来源不明代码。** 独立编码夹具与真机导入样例通过后才从“待接入”改为“可导出”。

## 10. 分期与验收

### P0 · 模型与导出通路确认
完成 V2 schema/迁移、坐标和效果编译夹具；分别核对静态 GIA 的父子/参数保存与 Lua 输出的赋值/挂载。明确整合 GIA codec 选型和许可。没通过时 UI 允许设计预览，导出明确显示受限能力。

### P1 · 静态创作闭环
裁切组、双色、高光；手柄、撤销、复制/收藏；JSON/PNG/SVG-CSS/Lua 输出。前后端同一输入得到相同编译结构、几何与成本。旧无效果 demo.css、JSON、Lua 回导不回退。

### P2 · 客户端整合 GIA
新 target 显式切换、导入结构校验、原生资源身份和文本排版核验；无脚本静态包与按需携带脚本的包分别标记验收范围。真机回传仅覆盖本工具新导出包，完成后才开放对应下载。不重复要求已有 MASK 探针 A–G 的基础测试。

### P3 · 动效（后续）
静态高光可切换扫光，提供时长/停顿/循环；Tween 任务由生命周期统一管理，不逐帧创建，移动补偿保证字形固定。多色与圆形另做能力扩展。

### 必须通过的检查

- 一份源文字改为长文案、换字号、换行后无重影；两份内容最终矩阵与样式一致。
- PNG/Web 对比：硬边、X/Y 羽化、重叠子图、透明遮罩、独立兄弟、嵌套组合、0 尺寸、视窗裁切与 high-DPI。
- 同一效果多次编辑只产生当前版本；删除组/undo/redo 不遗留编译副本和纹理。
- Lua VM 验证实际创建父级、字段、整数字号、资源、层序、错误和释放；只看接口可读写不算视觉验收。
- 客户端 GIA 源码/挂载/层级和四平台变换往返；不支持目标明确失败；无静默丢效果。
- 100 个小图元裁切 PNG 按组/局部区域处理；设性能预算前先在同一机器测基线，不把一次耗时写为所有机器承诺。
- 只长期维护代表性回归和小型共享夹具。一次性生成脚本、截图采样脚本在验收后删除，已交付作品及真机证据归档保留。

## 11. UI 稿的可用边界

`docs/ui/mask-effects.html` 用内嵌 SVG 和原生 JS 展示三个核心流程。导出按钮打开**计划对话框**，只允许下载 UI 配置快照，并明确不是 Scene V2 文件；Lua 和 GIA 不假装已经生成。它用于确定布局、字段和交互，正式实现应复用上面的统一编译语义，不能复制 UI 稿的展示代码当游戏渲染契约。
