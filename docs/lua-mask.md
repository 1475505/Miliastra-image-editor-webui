# Lua 导出、蒙版与羽化

[返回使用指南](README.md)

## 使用导出的 Lua

1. 在千星编辑器准备干净的客户端控件模板，并设为“仅存为模板”。图片或蒙版需要图片控件；文字需要文本框。
2. 在本工具选择「导出 → Lua」，或「复制 Lua 绘制脚本」。填写脚本顶部的真实模板索引：

   ```lua
   local IMAGE_PREFAB_ID = 0   -- 图片控件模板索引
   local TEXTBOX_PREFAB_ID = 0 -- 文本框模板索引（含文字时）
   ```

3. 在游戏编辑器建立脚本映射，将脚本挂到**专用空客户端容器节点**。脚本启动时自动创建图元；不要挂在会被实例化的模板上。
4. 保存并试玩，检查文字、层级、素材和蒙版效果。

`0` 表示尚未配置，不能直接使用。素材图片 ID、元件 ID 与控件模板索引是不同编号。脚本会设置宿主的尺寸和变换，因此应使用专用容器。

Lua 支持图片与原生文本框。纯文字且没有蒙版时无需图片模板。元件 ID 保存在脚本的 `PREFAB_IDS` 表中，无需另建同名客户端脚本参数。

导出的 Lua 可以重新导入编辑；请保留末尾编辑器数据注释。导入只读取支持的绘图数据，不执行脚本，也不还原任意游戏逻辑或运行时动画。

## 设置蒙版

选中图元 → **图元 → 高级**。

| 设置 | 用法 |
|---|---|
| 蒙版图片 ID | 默认 `100001` 矩形；`100002` 为圆形。点击缩略图打开选图面板，也可手填 ID 后按 Enter |
| 图片类型 | 保持默认、基础、拉伸；可选类型共用图形库的素材边框判断 |
| 启用蒙版 | 仅保留蒙版覆盖的内容 |
| 区域反转 | 交换保留和遮住的区域 |
| 偏移 X/Y | 相对原图元中心；X 向右，Y 向下 |
| 尺寸跟随图元 | 不单独指定宽高；手填 `0` 表示零尺寸 |
| 羽化 | 让边缘逐渐透明；开启羽化也会使用蒙版 |

选图时可按 ID、名称、用途搜索，或使用六种形状快捷按钮。选中候选会临时预览；「使用此蒙版」保存图片和类型，取消恢复。换到不支持拉伸的图片时，显式拉伸调整为基础；“保持默认”沿用原生类型。

**蒙版作用于当前图元。** 导出会创建一个透明图片父控件，把原文字或图片放到它下面；不会影响画布上的兄弟图元。蒙版窗口不随原图元旋转，改变蒙版尺寸也不缩放原内容。

## 看懂辅助预览

「显示蒙版辅助预览」默认开启：

- 原内容保持可见。
- 细虚线标出蒙版轮廓，圆环同时标出内外边界；放大画布时线宽保持轻细。
- 半透明素材按各独立图案的相对透明度提取辅助外形，避免固定阈值造成假缺口；实际裁切仍使用原图透明度。
- 灰色半透明覆盖表示被遮区域，羽化和反转也会反映在覆盖上。
- 关闭辅助显示，查看实际裁切画面。

独立蒙版小图中，白色表示保留，透明表示裁掉，绿虚线是原图元范围。辅助显示只用于编辑当前选中图元，不写入作品或导出；选择候选也不会提前修改场景。

## 羽化怎么调

**像素模式（Pixel）**：水平宽度控制左右，垂直宽度控制上下；数值越大过渡越宽，`0` 为硬边。例如 X=20、Y=0 可先观察左右渐隐。

**百分比模式（Percentage）**：网页将“范围”近似解释为中心不透明区域的占比。85% 表示两侧各 7.5% 渐隐，100% 为硬边；这是预览约定，不是已确认的原生公式。

切换模式会保留另一模式的数值，可展开“另一模式的原生参数”查看。JSON 和 Lua 保存原值。

## 保存与限制

- 启用蒙版或羽化的作品只能保存 JSON、导出 Lua；GIA/CSS/SVG/PNG 出口会提示不支持。
- 完全关闭效果需同时关闭蒙版和羽化。
- 基础形状按编辑器几何预览，其它图片按透明轮廓与切片预览。非矩形羽化、反转、百分比和混合效果仍须真机确认。
- 图片加载失败时显示原内容及提示；可重试。网页显示正确不等于真机已通过。

示例：[蓝金渐变字](../demo/gradient-text.md)。它用完整蓝字叠加蒙版中的金字，共两份文字与一个蒙版。
