# 图元高级：蒙版与羽化（仅 Lua）

选中图元 → 右侧【图元】→【高级】。基本图形、素材、元件和文本框均可设置。

- **蒙版**：图片 ID、启用、区域反转、中心偏移、宽高；空尺寸跟随图元，0 为零尺寸。`luaMask.imageId` 默认 `100001`（矩形），可以填写其它静态图片素材 ID；它不是图片控件模板索引，也不改变原图元的图片。
- **蒙版图片类型**：`luaMask.imageType` 可选 `basic`（基础）、`stretch`（拉伸）或 `null`（保持默认）。只设置蒙版父图片，独立于源图元的图片类型；切换不改宽高、位置或羽化参数。基础为整图缩放；拉伸用于支持切片边框的图片，具体轮廓与羽化组合需真机核验。
- **羽化**：启用后自动使用上述图片蒙版；模式为像素 / 百分比，配置水平/垂直宽度及范围。
- 数值原样传给 Lua，不将百分比除以 100、不假定原生曲线。模式切换保留数值。0、85 等初值是本工具的配置初值，不是所有模板的官方默认值声明。

当前为 **Lua 绘制能力**：JSON、收藏、复制和 Lua 回导保留 `luaMask`。默认图片 `100001` 实时预览矩形硬裁切、Pixel 和 Percentage 羽化（均为近似预览）；其它图片 ID 或反转启用时显示源图元，并提示轮廓/反转预览尚未支持，原值仍写入 Lua。启用蒙版或羽化的场景只允许 Lua/JSON 导出，关闭两项后恢复其它格式（已有元件限制仍适用）。蒙版为当前图元自动加一个独立的透明图片父控件；没有新增任意分组系统。

旧 JSON / Lua 缺少 `imageId` 时沿用 `100001`，旧 Lua 元数据摘要保持兼容。工具输入限定为 `1–2147483647` 的整数，拒绝字符串、布尔值、小数和越界值；这是工具校验范围，不是官方资源存在性声明。自定义图片的轮廓取形、羽化及透明着色组合仍需真机验证。

图片类型默认为“保持默认”：省略或 `null` 都不赋值，沿用绑定图片后的原生类型，保留旧作品行为。显式选择不会因更换图片 ID 被自动清除；JSON、收藏、复制、撤销和 Lua 回导保留选择。网页仍只近似预览默认矩形，其余图片不模拟轮廓或九宫格蒙版。

像素模式使用宽度：启用羽化并设置 X=20、Y=0 可观察左右渐隐，范围值不参与 Pixel 预览。百分比模式使用水平/垂直范围，模式无关的原生参数折叠显示并保留。选框与变换手柄放在蒙版外层，图元完全裁掉后仍能选择和调整。

### 百分比预览约定

原生 API 尚未明确范围的计算公式；这里采用**编辑器近似策略**，不是新增真机结论：范围 r 视为中心不透明区域占该轴的百分比，每侧线性过渡宽度为 `轴尺寸 × (1 - clamp(r,0,100)/100) / 2`。X/Y 各自计算，中心不透明，边界外为透明。

- 85%：中间 85% 不透明，两侧各 7.5% 渐隐。
- 50%：中间 50% 不透明，两侧各 25% 渐隐；比 85% 更柔。
- 100%：无渐隐，保持硬边；0%：两边渐变延伸到中心。

切换模式不改任何保存值。超出 0–100 的范围仅在**预览计算**中截断；JSON/Lua 保留输入原值。Percentage 预览不再使用 Pixel 宽度，也不把范围折算写回 `softEdgeWidthX/Y`。范围语义需要真机证据后才能调整为精确还原。

## Lua 导出

沿用 `IMAGE_PREFAB_ID`、`TEXTBOX_PREFAB_ID`；即使作品只有文字，启用蒙版/羽化也需要图片控件模板索引。模板应为干净模板，不要挂同一绘制入口脚本。

工具生成脚本内容，不会自动在真机编辑器建立映射或挂载。用户填写真实模板索引、建立脚本映射并把脚本挂到专用客户端容器后，运行时才自动生成下面的层级与参数；不需要为每个图元单独挂脚本。

可用示例：[双色渐变字 Lua / JSON](../demo/gradient-text.md)，由两份重合文字和一个透明羽化蒙版构成。

```text
脚本宿主
├─ 透明图片蒙版（默认矩形）
│  └─ 原图元（图片 / 文本框）
└─ 其它图元或其蒙版分支
```

蒙版通过 `SetImage(Enum.ImageSource.StaticReference, entry.imageId or 100001)` 绑定，并读回核对图片来源和 ID；图片颜色 alpha=0，保持激活、可见，`enableMask=true`。Lua 写入 `enableSoftEdge/softEdgeMode/SetSoftEdgeWidth/horizontalSoftRange/verticalSoftRange/reverseMaskArea`，关闭无关填充。无需容器模板。

显式图片类型在资源绑定后、显示前，用 `pcall` 设置 `Enum.ImageType.Basic/Stretch` 并读回核对。`imageType` 是条件能力；赋值报错或读回不符时，继续使用当前类型，以普通日志提示，同一图片 ID/类型每个脚本实例只提示一次。未选择类型时不访问该字段。无效类型在 JSON/Lua 导入时拒绝；手改运行数据也有运行时校验。

窗口与画布轴对齐，不跟随图元旋转；偏移相对原图元中心，编辑器 Y 向下。图元仍保留原来的缩放/XYZ 旋转。重挂到蒙版下时补偿锚点、轴心、尺寸差和位置，防止改变原内容布局；尺寸跟随使用原控件未旋转宽高（包括其原有拉伸锚点/缩放）。更改蒙版宽高不会缩放源内容。界面的画布整体缩放只缩放几何及 Pixel 宽度，Percentage 和范围原值保留。

`IMAGE_MASKS`、`TEXT_MASKS` 是与原图片/文字记录一一对应的受限字面量表。它们参与绘图摘要；修改后回导解析当前值，不能恢复过期元数据。没有蒙版记录的旧 Lua 仍可导入。上传的 Lua 从不执行。

带蒙版路径有启动重入保护；创建失败回收本轮已创建控件并记录错误；宿主 OnDestroy 时不重复销毁其子树。仅被动配置不启动 Tween，也不增加逐帧回调。
