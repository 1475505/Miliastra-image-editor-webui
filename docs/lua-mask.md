# Lua 导出、蒙版与羽化

[返回使用指南](README.md)

## 使用导出的 Lua

1. 在千星编辑器准备干净的客户端控件模板，并设为“仅存为模板”。图片或蒙版需要图片控件；文字需要文本框。
2. 在本工具选择「导出 → Lua」，或「复制 Lua 绘制脚本」。填写脚本顶部的真实模板索引：

   ```lua
   local IMAGE_PREFAB_ID = 0   -- 图片控件模板索引
   local TEXTBOX_PREFAB_ID = 0 -- 文本框模板索引（含文字时）
   ```

3. 在游戏编辑器建立脚本映射，将脚本挂到**专用空客户端容器节点**。脚本启动时自动创建图元；不要挂在会被实例化的模板上。
4. 保存并试玩，检查文字、层级、素材和蒙版效果。

`0` 表示尚未配置，不能直接使用。素材图片 ID、元件 ID 与控件模板索引是不同编号。脚本会设置宿主的尺寸和变换，因此应使用专用容器。

Lua 支持图片与原生文本框。纯文字且没有蒙版时无需图片模板。元件 ID 保存在脚本的 `PREFAB_IDS` 表中，无需另建同名客户端脚本参数。

导出的 Lua 可以重新导入编辑；请保留末尾编辑器数据注释。导入只读取支持的绘图数据，不执行脚本，也不还原任意游戏逻辑或运行时动画。

## 设置蒙版

选中图元 → **图元 → 高级**。

| 设置 | 用法 |
|---|---|
| 蒙版图片 ID | 默认 `100001` 矩形；`100002` 为圆形。点击缩略图打开选图面板，也可手填 ID 后按 Enter |
| 图片类型 | 保持默认、基础、拉伸；可选类型共用图形库的素材边框判断 |
| 启用蒙版 | 分区生效开关：开启后窗口裁切、羽化与填充实际生效并导出；关闭时配置仅在选中的图元上预览 |
| 遮罩区域反转 | 仅在蒙版矩形内交换保留和遮住的区域，框外仍裁掉 |
| 偏移 X/Y | 相对原图元中心；X 向右，Y 向下 |
| 尺寸跟随图元 | 不单独指定宽高；手填 `0` 表示零尺寸 |
| 羽化 | 让边缘逐渐透明；单独开启仅作预览，导出仍以「启用蒙版」为准 |
| 进度填充 | 按进度显示图片的一部分；设置归在蒙版分区，可与蒙版独立启用；仅图片类图元可用，文本框不支持 |

选图时可按 ID、名称、用途搜索，或使用六种形状快捷按钮。选中候选会临时预览；「使用此蒙版」保存图片和类型，取消恢复。换到不支持拉伸的图片时，显式拉伸调整为基础；“保持默认”沿用原生类型。

**蒙版作用于当前图元。** 导出会创建一个透明图片父控件，把原文字或图片放到它下面；不会影响画布上的兄弟图元。蒙版窗口不随原图元旋转，改变蒙版尺寸也不缩放原内容。

## 看懂画布预览

「显示蒙版轮廓」默认开启：

- 启用蒙版后，画布直接显示裁切后的效果，不再叠加原内容。
- 细虚线标出蒙版轮廓，圆环同时标出内外边界；放大画布时线宽保持轻细。
- 半透明素材按各独立图案的相对透明度提取辅助外形，避免固定阈值造成假缺口；实际裁切仍使用原图透明度。
- 未启用蒙版时，选中图元仍在「高级」页中实时预览配置效果；分区标题旁会显示「预览」标记。取消选择或离开高级页即恢复完整图元。轮廓与标记不写入作品或导出。

独立蒙版小图中，白色表示保留，透明表示裁掉，绿虚线是原图元范围。预览只用于编辑当前选中图元，不写入作品或导出；选择候选也不会提前修改场景。

## 羽化怎么调

**像素模式（Pixel）**：水平宽度控制左右，垂直宽度控制上下；数值越大过渡越宽，`0` 为硬边。例如 X=20、Y=0 可先观察左右渐隐。

**百分比模式（Percentage）**：网页将“范围”近似解释为中心不透明区域的占比。85% 表示两侧各 7.5% 渐隐，100% 为硬边；这是预览约定，不是已确认的原生公式。

切换模式会保留另一模式的数值但不显示；JSON 和 Lua 仍保存原值。

## 进度填充怎么调

进度填充只作用于图片类图元（形状、图片、元件），**文本框不支持**。面板按 ugc-tool 与羽化字段平铺在蒙版分区内；羽化与填充的开关只决定各自效果是否参与，实际生效与导出仍以「启用蒙版」为准——关闭时整组仅为选中图元的编辑预览。填充与窗口裁切同时生效时，最终显示为两者的交集。

| 设置 | 用法 |
|---|---|
| 填充方式 | 横向、纵向、90° 环绕、180° 环绕、360° 环绕 |
| 方向 | 横向从左至右／从右至左；纵向从上至下／从下至上 |
| 环绕起点 | 90° 可选四角；180°/360° 可选四边 |
| 填充量 | 面板为 0–100 滑杆与数字；模型与 Lua 仍传 `0–1`（73 → 0.73），容器 GIA 写整数百分比 |

- Lua 使用官方脚本 API 的 `SetFillHorizontal/Vertical/Radial90/Radial180/Radial360`；环绕始终顺时针，API 没有方向开关。面板百分比只用于显示，保存与 Lua 传参仍是 `0–1`。
- 容器节点 GIA 写入填充开关、方式、方向/起点和整数百分比进度（如 `0.71` → 71）；`0.715` 这类值会报错。字段编号与枚举顺序对齐 ugc-tool 的 84 组件映射，方向/起点的真机语义仍待验证。环绕固定顺时针（505 保持模板默认 1），不提供方向开关。
- 画布预览为近似：横向/纵向按边界线性裁切，环绕按锥形角度扫描，非真机公式。

## 保存与限制

- 启用蒙版的作品可保存 JSON、导出 Lua 或容器节点 GIA。容器节点 GIA 把蒙版导出为透明父图片控件，与 Lua 的父子控件结构一致。CSS/SVG/PNG/素材组 GIA 会提示不支持。
- 未启用蒙版时，羽化与填充的配置仅存于 JSON（编辑预览数据），不写入任何导出。
- 基础形状按编辑器几何预览，其它图片按透明轮廓与切片预览。非矩形羽化、反转时的半透明边缘、百分比、填充与混合效果仍须真机确认。
- 图片加载失败时显示原内容及提示；可重试。网页显示正确不等于真机已通过。

示例：[蓝金渐变字](../demo/gradient-text.md)。它用完整蓝字叠加蒙版中的金字，共两份文字与一个蒙版。
