# 多选、鼠标与快捷键

[返回使用指南](README.md)

## 选择图元

- **单选**：直接点图元或图层。
- **增选／减选**：画布上按 Shift 或 Ctrl/⌘ 点选。
- **连续选择**：图层列表按 Shift 点选，以最近单击的图层为起点；Ctrl/⌘ 切换单项。
- **框选**：在空白处拖框，碰到图元范围即选中；按 Shift/Ctrl/⌘ 可追加。
- **取消**：点空白处或按 Escape。拖动途中按 Escape 会恢复操作前状态。

透明或被蒙版裁掉的内容仍可选择。多选显示整体虚线边框；拖动任一已选图元可整体移动，Alt 拖动会复制整个选择。单图元继续使用原来的缩放和旋转手柄。

## 常用快捷键

Windows/Linux 用 Ctrl，macOS 用 ⌘。顶部「快捷键」或 `?` 可在页面内查看。

| 操作 | 快捷键 |
|---|---|
| 全选 | Ctrl/⌘+A |
| 复制／剪切／粘贴 | Ctrl/⌘+C / X / V |
| 原位粘贴 | Ctrl/⌘+Shift+V |
| 创建副本 | Ctrl/⌘+D |
| 删除所选 | Delete / Backspace |
| 微调 1px / 10px | 方向键 / Shift+方向键 |
| 下移／上移一层 | Ctrl/⌘+[ / ] |
| 置底／置顶 | Ctrl/⌘+Shift+[ / ] |
| 撤销／重做 | Ctrl/⌘+Z / Shift+Z，或 Ctrl/⌘+Y |
| 保存并应用 | Ctrl/⌘+S |
| 适应窗口／100% | Ctrl/⌘+0 / 1 |
| 放大／缩小 | Ctrl/⌘++ / − |
| 平移视图 | 空格+拖动／中键拖动 |

多选时，移动、复制、删除和调层级作用于整个选择，保留内部相对位置和层序。鼠标拖动和方向键长按分别记为一步撤销。

复制粘贴目前用于当前页面；普通粘贴逐次偏移 10px，原位粘贴不偏移。文字、蒙版和素材设置一起复制。输入框、可编辑文本、弹窗和输入法组合输入保留自身键盘操作。
