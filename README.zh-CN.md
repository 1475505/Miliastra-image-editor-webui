# 千星图片编辑器

**中文** · [English](README.md) · [在线使用](https://qx.070077.xyz/)

一款在浏览器里作图的小工具，为《千星奇域》的创作者准备：把游戏自带的图片素材、基本图形和可编辑的文字放到同一张画布上拼合，再导出成游戏编辑器可用的界面素材（GIA）或 Lua 绘制脚本。

打开网页就能用，无需安装。你可以自己动手摆，也可以让支持 WebMCP 的 AI 客户端替你操作画布。

![编辑器界面](docs/screenshot.png)

## 三步开始

1. 打开[编辑器](https://qx.070077.xyz/)，从左侧「图形库」把图形或游戏素材拖到画布上，双击也可以。已有 CSS、SVG、JSON 或 Lua 文件，可以从「导入」进来接着编辑。
2. 在画布上拖动、缩放、旋转图元，在右侧「属性」面板里改文字、颜色、图片类型和蒙版。按住 Shift 逐个点选，或在空白处拖框，可以一次选中多个。
3. 想下次接着改，用「导出 → JSON」保存；想带进游戏编辑器，选 GIA 或 Lua。

第一次打开会自动出现「快速上手」引导，之后随时可以点顶部的「上手」再看一遍。

> **编辑器不会自动保存作品。**「保存并应用」（快捷键 `Ctrl/⌘+S`）只是把画布上的图元同步到代码预览和图形库的「已保存图元」里，方便以后重复使用，它不会生成文件。刷新或关闭页面前，请先导出。

## 主要功能

- **基本图形**：矩形、圆形、三角形、星形、圆环。
- **游戏图片素材**：内置素材库，可搜索、按分类筛选；支持「基础／拉伸」两种图片类型、单色素材染色和图层排序。
- **可编辑文本框**：支持富文本、字号自适应、描边和对齐，导出后是游戏里的原生文本框。
- **顺手的编辑操作**：多选、框选、整体移动、复制粘贴、撤销重做，常用操作都有快捷键。
- **图片蒙版**：蒙版、羽化和进度填充会随 Lua 或容器节点 GIA 一起导出；被遮住的内容可以用虚线轮廓和半透明覆盖显示出来。
- **元件**：输入元件 ID 查询缩略图，拖进画布后可用 Lua 绘制。

## 如何选择导出格式

| 格式 | 用途 | 注意事项 |
|---|---|---|
| JSON | 保存作品、继续编辑 | 保留场景设置和已保存图元 |
| Lua | 在客户端 UI 中绘制原生图片与文字 | 填写真实控件模板索引，并映射、挂载脚本 |
| GIA | 导入游戏编辑器的界面素材组 | 含元件或已启用图元蒙版的作品改用 Lua 或容器节点 GIA |
| 容器节点 GIA | 导入为客户端控件模板，图元即其图片子控件 | 无需脚本；图元蒙版与进度填充一并导出；文本框、元件与圆形画布遮罩暂不导出 |
| CSS / SVG | 分享或使用支持的图元子集 | SVG 会省略圆环，复杂 SVG 不保证无损回导 |
| PNG | 通过 API 或 AI 工具获取渲染图 | 含元件或已启用图元蒙版时不可用 |

画布背景仅用于查看。导出需要实色底时，添加铺满画布的矩形。网页蒙版效果为近似预览，最终效果请在游戏中检查。

## 常用操作

Windows/Linux 使用 `Ctrl`，macOS 使用 `⌘`。

- Shift 点选增减选择；图层列表 Shift 连选。
- 空白拖动框选；空格拖动或中键拖动平移视图。
- `Ctrl/⌘+A、C、X、V、D`：全选、复制、剪切、粘贴、创建副本。
- 方向键微调 1px，Shift+方向键为 10px；Delete 删除所选。
- `Ctrl/⌘+Z` 撤销，`Ctrl/⌘+Shift+Z` 或 `Ctrl/⌘+Y` 重做。
- 顶部「快捷键」或 `?` 查看完整键位。输入框和弹窗保留自身按键。

## WebMCP：让 AI 帮你拼图

如果你用的浏览器或 AI 客户端支持 WebMCP，可以把画布交给 AI 操作：搜索素材、查看画面、批量修改、导入导出和撤销都能代办。打开编辑器后，先让 AI 列出当前页面的工具，再描述你的需求，例如：

> 保留现有作品，做一张 600×400 的标题卡：深色底、三个图片元素和居中标题。完成后导出 JSON。

AI 操作的是当前打开的页面，本项目不提供独立的 MCP 服务。如果 AI 没有发现这些工具，请检查浏览器接入是否提供 `document.modelContext.registerTool`；普通浏览器仍可手动使用。

## 本地运行

准备 **Python 3.13** 和 **Node.js 20+**（含 npm），下载源码后在仓库根目录执行：

```powershell
# Windows PowerShell
.\start.bat
```

```bash
# Linux / macOS
bash start.sh
```

启动脚本会安装依赖、构建前端并启动服务，访问 **http://localhost:8439**。也可以直接使用 Docker，镜像构建时会自动编译前端：

```bash
docker build -t miliastra-image-editor .
docker run --rm -p 8439:8439 miliastra-image-editor
```
